# Shu Blog

> 记录学习过程，分享项目经验

## 项目简介

个人学习博客，包含前端展示和后台管理系统。

- **前端**: Vue 3 + Vite，部署在 [GitHub Pages](https://shuhunb515.github.io/shu-Blog/)
- **后端**: Python Flask，部署在 [PythonAnywhere](https://shuhuNB560.pythonanywhere.com/)
- **访问地址**: [https://shuhu.me/shu-Blog/](https://shuhu.me/shu-Blog/)

## 功能模块

| 模块 | 说明 |
|------|------|
| 学习过程 | HTML & CSS、JavaScript、Python、Vue 3、Python 算法竞赛 |
| 项目展示 | OS Kernel、Linux 发行版、D-Bus 组件 |
| 管理中心 | 浏览量统计、内容编辑 |
| CTF 博客 | [https://shuhunb515.github.io/shu-CTF-blog/](https://shuhunb515.github.io/shu-CTF-blog/) |

## 技术栈

- **前端**: Vue 3、Vue Router、Vite
- **后端**: Flask、SQLite、Flask-CORS
- **部署**: GitHub Pages (前端) + PythonAnywhere (后端)

## 本地开发

```bash
# 前端
cd frontend
npm install
npm run dev

# 后端
cd backend
pip install -r requirements.txt
python app.py
```
